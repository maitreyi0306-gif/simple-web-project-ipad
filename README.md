# Simple Web Project

This is a tiny static web project you can open and edit from your iPad.

Files included:

- index.html — main page
- style.css — styles
- script.js — small interactive script

Preview options (iPad-friendly)

1) Quick preview via StackBlitz (no setup):
   Open this URL in Safari or the StackBlitz app:
   https://stackblitz.com/github/maitreyi0306-gif/simple-web-project-ipad

2) GitHub Pages (persistent public URL):
   - Open your repository on GitHub: https://github.com/maitreyi0306-gif/simple-web-project-ipad
   - Go to Settings → Pages and choose branch `main` and folder `/ (root)` then Save.
   - The site will be published at `https://maitreyi0306-gif.github.io/simple-web-project-ipad/` (may take a minute).

3) Edit files on your iPad:
   - Use the GitHub web editor: open a file and click the pencil icon to edit.
   - Or import into StackBlitz to edit live.

If you want, I can add a GitHub Action to automatically publish to GitHub Pages (one-click), or I can enable Pages for you if you give permission. Otherwise, enable Pages from the repo Settings as described above.
